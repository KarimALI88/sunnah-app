# سكينة (Sakinah) - تطبيق إسلامي معاصر للأذكار ومواقيت الصلاة

تطبيق إسلامي حديث مبني بأحدث معايير **React Native**, **Expo**, **TypeScript**, **Expo Router**, و **TanStack Query** ومستوحى بنسبة ١٠٠٪ من تصاميم **Google Stitch (Sakinah Spiritual Serenity)**.

---

## 🌟 مميزات التطبيق

1. **الرئيسية (Home)**:
   - تحية إسلامية مخصصة وتاريخ هجري وميلادي مع المدينة الحالية.
   - بطاقة الصلاة القادمة بنظام التوهج المحيطي، مؤقت تنازلي حيّ، ومؤشر نسبة مئوية.
   - شريط أفقي مدمج لجميع مواقيت صلاة اليوم مع تمييز الصلاة النشطة.
   - شبكة الوصول السريع لأبواب الأذكار، الأدعية، الرقية، وأسماء الله الحسنى.
   - ملخص الأوراد الشخصية مع إمكانية التسبيح المباشر.
   - فائدة اليوم الإيمانية.

2. **الأذكار اليومية (Azkar & Duas)**:
   - تصنيف هرمي دقيق: أقسام رئيسية ← أقسام فرعية ← نصوص الأذكار.
   - شريط بحث فوري في الأذكار والأدعية.
   - بطاقة الورد الحالي المقترح.
   - بطاقات الأقسام (أذكار الصباح، المساء، النوم، الاستيقاظ، بعد الصلاة، السفر، تفريج الكرب...).

3. **شاشة القراءة والعداد (Dhikr Recitation & Counter)**:
   - نصوص الأذكار مكتوبة بخط المصحف الشريف (Amiri) مع التشكيل الدقيق.
   - بيان الفضل والأثر وتخريج الحديث ووسم "مأثور صحيح".
   - عداد دائري تفاعلي مع حلقة تقدم SVG واهتزاز لمسي (Haptic Feedback) عند كل ضغطة.
   - أزرار التحكم (السابق، إعادة، التالي) ومودال تأكيد الخروج مع حفظ مكان الوصول.
   - محاكي الاستماع الصوتي بصوت الشيخ مشاري العفاسي.

4. **مواقيت الصلاة (Prayer Times)**:
   - حساب وتوزيع الصلوات الخمس مع وقت الشروق.
   - عداد تنازلي دقيق حتى موعد الأذان القادم مع تقدم دائري.
   - مفاتيح تشغيل/كتم الأذان لكل صلاة بشكل مستقل.
   - بطاقة إرشادية سريعة لاتجاه القبلة.
   - حاسبة أوقات قيام الليل، منتصف الليل، والثلث الأخير (وقت النزول الإلهي).

5. **وردي الشخصي (Personal Wird)**:
   - إنشاء وإدارة أوراد وتسبيحات مخصصة.
   - عداد يتجاوز الهدف المحدد للمداومة على الذكر (مثل ١٣٥ / ١٠٠).
   - إمكانية تصفير العداد أو تعديل نصوص الأوراد وحذفها.
   - بطاقة الإضافة بتصميم الخط المتقطع (Dashed card) مع مقترحات جاهزة لأشهر الأذكار.
   - حفظ وتخزين دائم على الجهاز عبر `AsyncStorage`.

6. **أسماء الله الحسنى (99 Names of Allah)**:
   - عرض كامل لأسماء الله الـ ٩٩ مرتبة بالأرقام المشرقية.
   - بحث فوري بالاسم أو المعنى أو الشرح.
   - بطاقة منبثقة تفاعلية لكل اسم تبرز المعنى، الشرح المفصل، والأثر الإيماني.

7. **بوصلة القبلة (Qibla Direction)**:
   - بوصلة تفاعلية دائرية تشير بدقة إلى الكعبة المشرفة بمكة المكرمة.
   - احتساب زاوية القبلة بناءً على موقع المستخدم وإحداثيات الكعبة (21.4225° N, 39.8262° E).
   - استشعار المحاذاة (ضمن ±6 درجات) مع تأثير توهج ذهبي واهتزاز نجاح تفاعلي.
   - دعم الوضع التجريبي والمحاكاة التلقائية عند غياب مستشعر البوصلة في بيئات الاختبار.

8. **الإعدادات والتخصيص (Settings)**:
   - بطاقة الحساب ووضع الضيف المحلي.
   - شريط تحكم بحجم خط الأذكار مع معاينة حية فورية.
   - اختيار القارئ المفضل للتلاوة الصوتية (مشاري العفاسي، سعد الغامدي، أحمد العجمي).
   - مفاتيح تنبيهات الأذان، أذكار الصباح والمساء، وقيام الليل.
   - نبذة عن التطبيق والإصدار.

## 🚀 تشغيل التطبيق محلياً

### المتطلبات الأساسية
- Node.js (v18 أو أحدث)
- تطبيق **Expo Go** على هاتفك الذكي (iOS أو Android) أو محاكي (Simulator / Emulator)

### خطوات التشغيل
1. التوجه لمجلد المشروع:
   ```bash
   cd "d:/ofx/azkar app/app with screens/sakinah"
   ```

2. تشغيل خادم التطوير:
   ```bash
   npx expo start
   ```

3. مسح الـ QR Code عبر كاميرا الهاتف (iOS) أو تطبيق Expo Go (Android).
   - للتشغيل على متصفح الويب للتجربة السريعة: اضغط `w` في الطرفية.

## 🔌 خطة ربط الـ APIs (Ready for Backend Integration)

التطبيق مهيأ بالكامل لاستقبال الـ APIs دون الحاجة لإعادة كتابة واجهات المستخدم:
- كل ميزة تعتمد على نمط **Repository Pattern**:
  - `src/features/azkar/services/azkar.repository.ts`
  - `src/features/prayer-times/services/prayerTimes.repository.ts`
  - `src/features/wird/services/wird.repository.ts`
  - `src/features/allah-names/services/allahNames.repository.ts`
- عند توفر الخادم، يكفي استبدال الدوال بطلبات شبكية عبر `src/api/client.ts` وستتكفل خطافات `TanStack Query` بجلب البيانات وتحديث التخزين المؤقت تلقائياً.

## 📱 اختبارات تتطلب جهازاً فعلياً (Physical Device)
- **مستشعر البوصلة (Magnetometer)**: تم تضمين محاكاة ذكية في بيئات التطوير، لكن قياس الزاوية المغناطيسية الفعلي يتطلب تشغيل التطبيق على هاتف حقيقي يدعم مستشعر البوصلة والموقع الجغرافي.
- **الاهتزاز اللمسي (Haptic Feedback)**: يعمل مباشرة على أجهزة iOS و Android الفيزيائية.
